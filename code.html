Як працює код сайту

Будь-який вебсайт або браузерна міні-гра складається з трьох головних технологій. Вони працюють разом як команда:

HTML будує скелет сторінки, CSS додає красу та кольори, а JavaScript змушує все рухатися та реагувати на кліки.

1. Базові теги HTML (Структура)

  • <!DOCTYPE html> — повідомляє браузеру, що це сучасна вебсторінка.
  • <html> — головний контейнер, всередині якого лежить весь код сайту.
  • <head> — прихована частина для налаштувань, шрифтів та назви вкладки.
  • <body> — видима частина сторінки, яку бачить користувач на екрані.
  • <h1> ... <h6> — заголовки різних розмірів (від найбільшого до найменшого).
  • <p> — звичайний текстовий абзац.
  • <div> — універсальний блок-коробка для групування елементів.
  • <a href="..."> — посилання для переходу на іншу сторінку або гру.
  • <button> — інтерактивна кнопка для натискання.
  • <img src="..."> — тег для вставки картинок.

2. Базові властивості CSS (Дизайн)

  • color — змінює колір тексту (наприклад, рожевий).
  • background — задає колір фону або плавний градієнт.
  • font-size — встановлює розмір літер.
  • width / height — задає ширину та висоту блоку чи картки.
  • margin — зовнішній відступ (відштовхує сусідні елементи).
  • padding — внутрішній відступ (створює простір всередині блоку).
  • border — малює рамку навколо елемента.
  • border-radius — заокруглює кути блоків та кнопок.
  • display: flex / grid — сучасні способи вирівнювання карток у ряд чи сітку.
  • :hover — задає вигляд елемента, коли на нього наводять мишкою.

3. Базові основи JavaScript (Логіка та ігри)

  • <script> — тег, у якому пишеться або підключається JS-код.
  • let / const — створення змінних для збереження даних (наприклад, рахунку в грі).
  • function ім'я() { } — блок коду, який виконує певну дію (наприклад, стрибок персонажа).
  • document.querySelector() — знаходить потрібний HTML-елемент на сторінці.
  • addEventListener('click', ...) — відстежує дії гравця (кліки мишкою, натискання клавіш).
  • if / else — перевірка умов (якщо гравець торкнувся ворога — гра закінчена).
  • Math.random() — генерує випадкові числа (потрібно для появи бонусів чи ворогів).
  • setInterval() — запускає дію по колу через кожні кілька мілісекунд (ігровий цикл).
